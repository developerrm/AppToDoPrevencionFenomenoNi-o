# Refugio — Lista para El Niño

Aplicación familiar para completar los recursos antes de lluvias e inundaciones en Guayaquil. SPA ligera hecha con React, Vite y Tailwind CSS; los datos de prueba se guardan localmente en localStorage.

## Desarrollo

```bash
npm install
npm run dev
```

El catálogo incluye misiones de agua y alimentos, energía, comunicaciones, botiquín, control de mosquitos, kit contra inundaciones, mochila, documentos, herramientas, mascotas y plan familiar. El plan ofrece un máximo de cinco misiones diarias; cada misión queda reservada al jugador que la toma. Al acabar las diarias se puede adelantar una misión recomendada.

La energía/HP es lúdica, no una medida de salud o seguridad. Para una fase en la nube, sustituir la persistencia local por un repositorio/API y agregar `familyId` a los registros.
